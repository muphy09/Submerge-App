# Fiberglass specification rollout

The application code adds model-specific pool, spa, and tanning ledge specifications for new proposals. Manufacturer values are absent from runtime defaults. The Latham data source is `scripts/data/latham-fiberglass-specifications.txt`; regenerate the two seed migrations with `node scripts/generate-fiberglass-spec-seed.cjs` only before applying them to a new database.

Production project `jhllbqzdapjeuuuuzcxh` received nine immutable specification-only revisions on September 23, 2026: eight current Latham catalogs in franchises 5555, 8669, and 9724, plus matching spas and ledges in 5555's older March catalog. The six Hydura shells, the March pool shells, Meridian spa, Gemini ledge, and Picasso ledge have no pictured match and remain manual.

**Activation completed September 23, 2026.** `20260923020000_hold_fiberglass_specifications_for_client_rollout.sql` temporarily restored the nine previous current-revision pointers while the existing-client prompt behavior was reviewed. The user approved the prompt, so `scripts/activate-fiberglass-specifications.sql` activated the nine seeded revisions after confirming every pointer and fiberglass catalog still matched its predecessor. Older installed application builds show their existing generic pricing prompt. The updated application shows the informational message “This model has been updated to work with Fiberglass Dimensions”; dismissing it does not change the saved proposal or its pricing review decision.

The activation script was guarded to abort unless all nine current pointers referenced their expected predecessor revisions and their fiberglass catalogs were unchanged. Do not rerun it after activation.

Pre-hold production evidence: each of the eight current Latham catalogs had 61 exact pictured pool matches, four spa matches, four ledge matches, and zero specification value mismatches. The six extra shells were Hydura. The March catalog had four spa and four ledge matches; its other entries remained untouched. Removing `specifications` from the nine new revisions yields the previous revision's full catalog values; all other pricing fields also matched. Before and after both seed migrations and the hold, the 441 proposals and 36 pre-existing revisions retained their exact aggregate JSON checksums: `70ac9583eb245dd699ae1cfe5cef58ee` and `0c2471e1009dbbc75e663617bda2c9c6`.

Post-activation verification found nine active seed revisions and each current model's fiberglass catalog matching its revision. Eight catalogs have 61/4/4 pool/spa/ledge specifications; the March catalog has 0/4/4. The 441 saved proposals and 36 earlier revisions retained their exact aggregate checksums before and after activation: `aa3a7917ceee00ec7b5c65696ae2d555` and `d681184b4ce0482730d498b6a36ca064`. Franchise 8669 was added to `release-state.json` so the global Electron release can build a channel for all three active franchises. Application distribution remains a separate release step through the repository's global Electron release workflow.
